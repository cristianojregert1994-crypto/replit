# Ícones da Extensão

Crie ou adicione os seguintes arquivos PNG nesta pasta:

- `icon16.png` - 16x16 pixels (toolbar)
- `icon48.png` - 48x48 pixels (extension management)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Como criar

1. Use qualquer editor de imagem (Figma, Canva, GIMP)
2. Crie um quadrado roxo (#7c3aed) com as letras "LG" em branco
3. Exporte nos 3 tamanhos acima

## Ou use um gerador online

- https://favicon.io/
- https://www.iconfinder.com/

A extensão funciona sem ícones mas他们会显示 um ícone genérico.
